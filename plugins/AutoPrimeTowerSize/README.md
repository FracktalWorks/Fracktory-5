# Auto Prime Tower Size Plugin for Cura

This plugin automatically sets the prime tower size based on the Z height of the loaded model(s).

## Features
- Listens for scene and setting changes
- Dynamically adjusts `prime_tower_size` based on model Z height
- No need to manually set the prime tower size for each print

## Installation
1. Copy the `AutoPrimeTowerSize` folder into your Cura `plugins` directory.
2. Restart Cura.
3. Enable the plugin in the Plugin Browser if needed.

## Customization
- You can adjust the scaling logic in `AutoPrimeTowerSize.py` as needed.
- Optionally, add a user setting to enable/disable the feature.
